# C-Style-Datastructures-Librairy
This is a little librairy I made for the most used datastructures in C, it contains all struct definition of these datastructures and some utils functions for it 

For now I have:
- Structs
   - List(int and str)
   - Stacks(int and str)
   - Queues(int and str)
     
-Functions
  - Lists(int and str)
      - To Add at the end of a list
      - Check if a value is inside the list
      - Get a list node from a given value
      - Free list memory
        
 -Stacks(int and str)
   - Push
   - Pop
   - Peek
   
 -Queues(int and str)
   - Enqueue
   - Dequeue
